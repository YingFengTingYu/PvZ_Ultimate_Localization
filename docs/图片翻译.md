# 图片翻译

菜单按钮、招牌和一些特效里的字是画在图片上的。翻译这些内容时，除了表达自然，也需要让文字融入原来的画面。

## 找到要改的图片

[assets/resources/locales](../assets/resources/locales)里按语言保存成品图片和翻译底稿：

| 目录 | 语言 |
| --- | --- |
| `en-us` | 英语 |
| `es-es` | 西班牙语 |
| `zh-cn` | 简体中文 |
| `zh-tw` | 繁体中文 |
| `de-de` | 德语 |
| `fr-fr` | 法语 |
| `it-it` | 意大利语 |
| `ja-jp` | 日语 |
| `ru-ru` | 俄语 |

先找到想修改的 PNG，再到 [source/locales](../source/locales) 的相同目录寻找同名 PSD。比如，游戏图片位于 `en-us/images/600/…/button.png`，对应源文件就在 `source/locales/images/600/…/button.psd`。

有 PSD 时可以直接编辑图层；只有 PNG 时，可以把它作为底图参考，制作自己的分层源文件。找不到对应源图时，先把成品图片发给维护者确认，再决定是否需要重绘。

## 编辑时留意什么

打开 PSD 后，先看看有没有语言组或字体备选层，找到对应文字再修改。同一个位置只显示需要的文字层，避免两种语言叠在一起。

**缺字体时请联系 [YingFengTingYu](https://github.com/YingFengTingYu)。** 仓库不附带字体文件，编辑器自动替换的字体可能与游戏效果不同。

排字时以游戏里实际显示的大小为准：较长的译文可以换一种简洁说法，也可以调整字号和行距，尽量避免把文字横向压得很窄。保持原有的颜色、描边和整体风格；按钮的普通、高亮和按下状态也要一起看。

导出 PNG 前，对照当前成品检查画布尺寸和透明背景。PSD 的画布不一定与成品相同，尤其要留意文字有没有贴边、阴影有没有被裁掉。

## 交稿时带上这些

- 可继续编辑的 PSD，保留文字和背景图层。
- 对应语言的 PNG 成品，沿用原文件名和目录。
- 一张预览图，或者游戏里的实际效果截图。

在 Pull Request 或交稿消息里注明语言、图片用途，以及修改了哪些按钮状态。还需要调整的地方可以直接说明，不必等所有图片都做好才交第一批。

不熟悉 Git 的话，把这些文件交给维护者就可以。字体文件不用打包，游戏资源的接入也由维护者处理。
