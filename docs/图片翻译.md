# 图片翻译

菜单按钮、招牌和一些特效里的字是画在图片上的。翻译这些内容时，除了表达自然，也需要让文字融入原来的画面。

## 找到要改的图片

[assets/resources/locales](../assets/resources/locales)里按语言保存成品图片和翻译底稿：

| 目录 | 语言 |
| --- | --- |
| `en-us` | 英语 |
| `es-es` | 西班牙语 |
| `zh-cn` | 简体中文 |
| `zh-tw` | 繁体中文 |
| `de-de` | 德语 |
| `fr-fr` | 法语 |
| `it-it` | 意大利语 |
| `ja-jp` | 日语 |
| `ru-ru` | 俄语 |

先找到想修改的 PNG，再到 [source/locales](../source/locales) 的相同目录寻找同名 PSD。比如，游戏图片位于 `en-us/images/600/…/button.png`，对应源文件就在 `source/locales/images/600/…/button.psd`。

有 PSD 时可以直接编辑图层；只有 PNG 时，可以把它作为底图参考，制作自己的分层源文件。找不到对应源图时，先把成品图片发给维护者确认，再决定是否需要重绘。

## 编辑时留意什么

打开 PSD 后，先看看有没有语言组或字体备选层，找到对应文字再修改。同一个位置只显示需要的文字层，避免两种语言叠在一起。

**缺字体时请联系 [YingFengTingYu](https://github.com/YingFengTingYu)。** 仓库不附带字体文件，编辑器自动替换的字体可能与游戏效果不同。

排字时以游戏里实际显示的大小为准：较长的译文可以换一种简洁说法，也可以调整字号和行距，尽量避免把文字横向压得很窄。保持原有的颜色、描边和整体风格；按钮的普通、高亮和按下状态也要一起看。

导出 PNG 前，对照当前成品检查画布尺寸和透明背景。PSD 的画布不一定与成品相同，尤其要留意文字有没有贴边、阴影有没有被裁掉。

## 交稿时带上这些

- 可继续编辑的 PSD，保留文字和背景图层。
- 对应语言的 PNG 成品，沿用原文件名和目录。
- 一张预览图，或者游戏里的实际效果截图。

在 Pull Request 或交稿消息里注明语言、图片用途，以及修改了哪些按钮状态。还需要调整的地方可以直接说明，不必等所有图片都做好才交第一批。

不熟悉 Git 的话，把这些文件交给维护者就可以。字体文件不用打包，游戏资源的接入也由维护者处理。

## 五种语言图片补全与校准（2026-10-30）

本轮校准 `source/locales` 的 32 份 PSD，并将工作区中的 124 张 PNG 重新导出接回游戏：德语、法语、意大利语各 20 张，日语、俄语各 32 张。PSD 中现有语言组都保留可编辑文字；已有对应语言且不在本轮改动清单中的成品保持原样。

排版基准：描边、浮雕、阴影和渐变对照《精华版字体.psd》；英文及德、法、意、俄的字身与布局对照游戏英文成品；中文与日语对照中文原稿。普通、高亮、按下状态若只改变颜色或效果，必须共用同一份文字几何参数，不能分别缩放后重新定位。

字体只使用游戏 `assets/files/fonts` 中的文件及其语言补字链。俄文菜单使用 `DwarvenTodCraftSymbols.ttf`，日文使用 `GraveBustedStoneLishuSc.ttf`；Zombatar 使用项目的 HouseOfTerror、Maoken、Nishiki 等字体。需要字体时联系维护者，不使用系统字体替换，不随本仓库分发字体。

woodsign3 要直接对照原稿木牌：标题描边为 1／2／3 像素，副标题保持紧密的两行排布。头像编辑器大标题的描边参数不能原样套到木牌；也不能因为副标题两行较近，就自行放大行距。

导出保持游戏成品尺寸。图鉴源稿为 95×97，成品为 99×99；原版生存按钮源稿为 262×123，成品为 266×123。采用居中扩展画布，并逐一检查文字、阴影、透明背景和状态切换。冒险按钮顶部文字还要给游戏动态绘制的关卡数字留出空间。

图鉴封面的小号俄文字不宜强行拉高或叠加强浮雕。当前普通／高亮已在 PSD 中调整字形比例和小字效果；两种状态仍共用文字位置。“更多游戏”的 PSD 以对应 `raw_puzzle` 普通／高亮模板重建，编辑时保留更多游戏文案，不能把原解谜模板的备选文字直接当作成品显示。

日语图鉴的同类重影已从普通／高亮两份源 PSD 修正：统一降低图鉴各语言文字层及字体备选层的过强浮雕，日语顶部小字适当放宽；中文顶部双行文字恢复原稿的字号与行距。普通／高亮共用日语文字几何参数。本次仅重导两张日语图鉴 PNG，保留底图、原文及此前修正的俄文字形；两仓同步检查通过。
