# 文字翻译

选一段你熟悉的内容开始就好，例如设置菜单、植物介绍或某个模式的说明。已有译文也欢迎修改；如果一句话读起来不像母语表达，可以结合游戏里的意思重新组织。

## 改哪些地方

每段文字上方都有一个方括号标识。例如：

```text
[PEASHOOTER]
Peashooter

[PEASHOOTER_TOOLTIP]
Shoots peas at the enemy
```

翻译下面的名称和说明，保留 `[PEASHOOTER]`、`[PEASHOOTER_TOOLTIP]` 这样的标识。游戏靠它们找到对应文字，所以不要翻译、重命名或删除它们，也不要在译文正文里新增方括号。

有些段落带有 `{SHORTLINE}`、`{KEYWORD}`、`{STAT}` 等标记，用来控制排版和文字样式。请保留这些标记，只修改它们旁边的正文。遇到表示数量、名称的占位符也要保留；不确定作用时，把标识和问题一起发给维护者。

先沿用原文的分段。短按钮尽量用简洁的词，说明文字则优先保证意思清楚。植物、僵尸和模式名称尽量与本语言已有译名一致；想改一个常用名称时，可以先提出建议，避免几个界面各用一个名字。

## 拿不准时怎么处理

笑话、双关和角色口吻不一定适合逐字翻译。可以给出你觉得自然的表达，并简单说明理由。机器翻译可以帮助理解，但交稿前请自己通读，尤其留意植物名称和技能效果。

如果缺少上下文，发出文字标识、所在界面或截图即可。不要为了凑齐进度把不确定的译文当作定稿；先把问题指出来同样有帮助。

## 把修改交回来

保存为 UTF-8，然后提交 Pull Request，或把修改后的文本文件交给维护者。附上一句说明：修改了哪种语言、哪一部分，以及有没有需要确认的译法。

如果能在游戏里看到这段文字，顺手检查是否被截断、换行是否自然。暂时无法测试也可以交稿，注明这一点即可，维护者会安排游戏内检查。
