# PvZ Ultimate Localization

一起完善《植物大战僵尸精华版》的多语言文字和图片。可以从一句不自然的翻译、一张按钮图片开始，也欢迎帮忙校对你熟悉的语言。

[文字翻译](docs/文字翻译.md) · [图片翻译](docs/图片翻译.md) · [English guide](docs/CONTRIBUTING.en.md)

## 从哪里开始

- 想翻译或润色文字：打开 [assets/files](assets/files)，找到对应语言的 `LawnStrings` 文件。[文字翻译指南](docs/文字翻译.md)里有编辑示例。
- 想修改图片上的文字：在 [source/locales](source/locales) 找同名 PSD 或 PNG，再对照 [现有语言图片](assets/resources/locales)制作。[图片翻译指南](docs/图片翻译.md)介绍了交稿方式。
- 发现错译、文字被截断或不知道一句话的含义：在 [Issues](https://github.com/YingFengTingYu/PvZ_Ultimate_Localization/issues) 附上截图和语言，我们一起确认。

想加入一种新语言，可以先联系 [YingFengTingYu](https://github.com/YingFengTingYu)，确认语言名称、字体和分工，再开始翻译。

## 怎么交稿

会使用 GitHub 的朋友可以提交 Pull Request，说明修改了哪种语言、哪个界面；图片修改请附预览。不会使用 Git 也没关系，把修改后的文件交给维护者即可，不需要安装游戏开发环境。

本仓库就是翻译和图片制作的协作入口。文字直接修改 `assets/files/LawnStrings_*.txt`，图片提交 PNG 和可编辑源文件。一次 PR 尽量围绕一种语言或一组素材，方便讨论和校对；维护者合并后再安排接入游戏。

需要字体时请联系 [YingFengTingYu](https://github.com/YingFengTingYu)，仓库里不附带字体文件。

## English

Help translate and improve PvZ Ultimate in your language. You can start with a few lines of text, a button image, or a correction to an existing translation.

Read the [contributor guide](docs/CONTRIBUTING.en.md) for where to find files, how to edit them, and what to send back. You do not need to build the game or know Git to help.

For fonts or a new language, contact [YingFengTingYu](https://github.com/YingFengTingYu).
